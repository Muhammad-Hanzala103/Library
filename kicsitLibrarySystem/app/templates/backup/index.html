⚠️ Critical Disaster Recovery Warning

  • Data Overwrite: Executing a backup restoration will completely overwrite the existing production database schema. All transactions, borrow history, catalog modifications, and accounts added after the backup time will be lost.
  • Session Interruptions: Restoring the database forces active users to be disconnected and may invalidate their current authentication tokens if the schema contains outdated sessions.
  • Librarian Verification: It is highly recommended to perform operations during low-traffic periods (e.g., late evenings or weekends) and verify database integrity immediately post-recovery.
